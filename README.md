Overview;

Go-Reloaded is a command-line text processing tool written in Go.

This project focuses on building the core foundation:
- Command-line interface (CLI)
- Reading input files
- Writing output files
- Processing pipeline structure (no transformations yet)

---

How it Works;

The program reads a text file and writes its content to an output file without modifying it.

---

Output:

```bash
go run . input.txt output.txt
